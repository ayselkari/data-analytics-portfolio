# Data Analytics Portfolio

Welcome to my Data Analytics Portfolio.

This portfolio includes personal projects using Excel, SQL and Power BI, with a focus on travel and tourism data.

## 🛠️ Skills & Tools

- Excel – Data analysis, formulas, Pivot Tables, dashboards
- SQL – Data querying, aggregation, filtering and business analysis
- Power BI – Data visualization, KPI dashboards and DAX

Analysis of travel booking data to understand revenue, profit, destinations and cancellation trends.

**Tools:** Excel

### 2. Hotel Booking Analysis — SQL
Analysis of hotel booking data including revenue, cancellation rates, room types and booking behaviour.

**Tools:** SQL

### 3. Tourism Performance Dashboard — Power BI
Interactive dashboard analysing tourism sales, revenue, customer segments, booking channels and destinations.

**Tools:** Power BI, DAX
